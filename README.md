# Site da Danielle Slawacki

Site institucional de **Danielle Slawacki** — Advogada Colaborativa e Mediadora, atuando com gerenciamento de conflitos familiares, societários, imobiliários e escolares.

O site apresenta o trabalho da Danielle, explica como funciona o processo de mediação, e ajuda quem visita a decidir se esse é o caminho certo pra situação dela — inclusive com um diagnóstico interativo (um quiz de 10 perguntas) que dá uma orientação inicial personalizada antes mesmo de marcar uma conversa.

**No ar em:** [slawacki.com.br](https://slawacki.com.br)

## O que tem na página

- **Abertura** — headline, foto e chamadas para o diagnóstico ou para agendar uma reunião de apresentação.
- **Quem sou eu** — apresentação profissional, formação acadêmica e certificações.
- **Áreas de atuação** — os quatro tipos de conflito atendidos (familiar, societário, imobiliário, escolar), cada um levando direto ao diagnóstico já com o tipo pré-selecionado.
- **O que esperar de uma sessão** — como funciona a mediação na prática.
- **Por que escolher a mediação** — principais benefícios da abordagem.
- **Método de trabalho** — as 4 etapas do processo, da reunião de apresentação até as sessões de mediação.
- **Diagnóstico inicial** — quiz interativo que gera uma orientação personalizada com base nas respostas.
- **Contato** — telefone/WhatsApp, e-mail e Instagram.

## Estrutura do repositório

- `index.html` — a página inteira (HTML, CSS e JavaScript, tudo em um único arquivo, sem etapa de build)
- `danielle-hero.jpg`, `danielle-about.jpg`, `danielle-bridge-family.png` — imagens usadas na página

## Identidade visual

- **Fontes:** Fraunces (títulos, com toque editorial) e Inter (textos, leitura confortável)
- **Cores:** tons de verde-azulado profundo (`#0B4A56`, `#0E6274`), azul-marinho (`#1E3350`), sálvia (`#A9BEC9`) e dourado (`#B68A52`) como destaque, sobre fundo creme (`#FAF7F1`)

## Hospedagem e domínio

- O site é hospedado na **Netlify**, com deploy automático direto deste repositório.
- Domínio próprio (`slawacki.com.br`) registrado via **registro.br**, apontado para a Netlify.

## Como atualizar

1. Edite os arquivos direto neste repositório (pelo GitHub web, ou clonando o repositório localmente).
2. Faça commit e push na branch `main`.
3. O deploy no Netlify acontece automaticamente a cada push — o site atualizado fica no ar em 1 a 2 minutos.
