# Site da Danielle Slawacki

Site institucional. Página única em HTML, sem build (só abrir/hospedar).

## Estrutura
- `index.html` — página principal
- `danielle-hero.jpg`, `danielle-about.jpg`, `danielle-bridge-family.png` — imagens usadas na página

## Como atualizar
1. Edite os arquivos direto neste repositório (pelo GitHub web ou clonando localmente).
2. Faça commit e push na branch `main`.
3. O deploy no Netlify é automático a cada push.
